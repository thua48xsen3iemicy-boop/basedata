# Учебные планы

Эталонная модель для формальной сборки: учебный план связан с `standard_id+edition`, outcome IDs, ограничениями суммарных и контактных часов, периодами и контрольными мероприятиями. Документ экспортируется как проекция данных. ФГОС-планы требуют проверки ответственным человеком.

`examples/example-plan.yaml` использует **условные** часы и только демонстрирует формат.
