# Будущие интеграции

Планируется двусторонняя граница между опубликованным manifest знания и внешними LMS. MVP должен оставаться полностью работоспособным без Moodle. Позже: адаптер публикации материалов, тестов, завершений и прогресса; приватная среда экзамена; рендер шаблонов административных документов; отдельный student UI. **На данном этапе ничего из этого не реализуется.**
