# Компетенции

Компетенции должны иметь независимые ID, проверяемые результаты и (при необходимости) уровень владения. Сейчас демонстрационный маршрут использует outcomes, заданные в `knowledge/.../unit.yaml`. На следующем этапе сюда выносится каталог компетенций и мэппинг разных стандартов на общие outcomes.
