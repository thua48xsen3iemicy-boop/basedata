# Вне текущего scope: интерфейс студента и Moodle

Позже нужен интерфейс student workspace: вход → назначенные курсы → следующий шаг → материал → тест/проверка → завершение. Минимум лишней навигации; крупные карточки, тёмный лаконичный IT-стиль, лёгкие эффекты, производительность браузера. Интерактивный локальный LLM-опрос — возможный тип активности. Преподавательский и административный UI может отличаться от студенческого. Сохранить возможность интеграции с Moodle и другими LMS через adapter/API.

**Не реализовывать UI, тему, дизайн-систему или Moodle-плагин на этапе проектирования базы и агентного конвейера.**
