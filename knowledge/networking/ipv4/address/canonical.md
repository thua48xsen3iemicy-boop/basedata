# Структура IPv4-адреса (учебный черновик)

IPv4-адрес представляет собой 32-битовое значение; в привычной десятичной форме оно записывается четырьмя октетами. Не путать само значение адреса и способ его текстовой записи.

Это демонстрационный материал без экспертного утверждения. Не расширять до полноценной темы в рамках каркаса.
