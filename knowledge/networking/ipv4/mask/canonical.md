# Маска сети (учебный черновик)

Маска определяет биты, используемые для выделения сетевой части адреса. Для получения адреса сети из адреса интерфейса и маски выполняют побитовое AND.

Разделять сетевой адрес, адрес хоста, адрес широковещания и правила использования адресов в конкретной конфигурации.
