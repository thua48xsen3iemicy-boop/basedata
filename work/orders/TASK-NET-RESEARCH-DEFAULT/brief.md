# Маршрут по умолчанию

Заказ: `TASK-NET-RESEARCH-DEFAULT`. Результаты: `work/research/TASK-NET-RESEARCH-DEFAULT/`.

## Вопросы исследования

- 0.0.0.0/0 как наименее специфичный префикс; отличие от адреса 0.0.0.0 и локального адреса
- Default route, default gateway и способ установки маршрута — разные понятия; здесь только статическая установка
- Таблица с connected, specific static и default: выбрать маршрут и ARP target; отсутствие подходящего маршрута и обратный путь

## Отправные источники (не проверены в рамках постановки)

- RFC 1122 §3.3.1: https://www.rfc-editor.org/info/rfc1122
