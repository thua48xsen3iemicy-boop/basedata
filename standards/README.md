# Нормативные стандарты

Здесь появятся неизменяемые снимки конкретных редакций документов. Начальный пример не содержит **никаких** нормативных утверждений и не претендует на соответствие ФГОС/другим стандартам. Будущая структура: `standards/<jurisdiction>/<framework>/<edition>/` с `manifest.yaml`, `requirements.yaml` и `mappings.yaml`. `source_url`, `edition`, `effective_from`, `retrieved_at`, `license/status` обязательны для импорта.
